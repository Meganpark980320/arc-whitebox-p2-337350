# <3,3,6;40> fast matrix multiplication coefficients (PLinOpt data)
Source: https://github.com/jgdumas/plinopt data/3x3x6_40_*.sms (commit in SOURCE_COMMIT), fetched 2026-10-12.
Authors: Jean-Guillaume Dumas, Clément Pernet, Alexandre Sedoglavic (see AUTHORS.md). Licence: CeCILL-B (copy included).
Files: L/R = left/right operand linear forms (40 rows), P = product recombination; "DPS-accurate" = numerically more accurate variant.
Format: sparse-matrix-SMS (rows cols type / i j value ... / 0 0 0).
Keep this README, AUTHORS.md and the licence with any package that uses these coefficients.
